# 🔀 redirect-generator

Генератор правил 301-редиректов для Apache и nginx. Отмечаешь нужные правила — получаешь готовый конфиг и команды для проверки.

## Что будет уметь

- **HTTP → HTTPS**
- **www ↔ без www** — выбор основного зеркала
- **Слеш в конце адреса** — добавлять или убирать
- **`index.php` / `index.html` → `/`**
- **Свои редиректы** — список «старый адрес → новый», можно вставить из таблицы
- Всё за **один переход**, без цепочек `301 → 301 → 200`
- Готовый **`.htaccess`** (Apache, mod_rewrite) и блок для **nginx**
- Команды **curl** для проверки каждого правила
- Скопировать в буфер или скачать файлом
- Работает прямо в браузере: без сервера, данные никуда не отправляются

## Запуск

Открыть `index.html` в браузере или поднять локальный сервер:

```bash
npx serve .
```

Тесты (Node.js 20+, без зависимостей):

```bash
npm test
```

## Структура

```
├─ index.html          страница с формой
├─ styles/
│  └─ main.css         стили
├─ src/
│  ├─ main.js          связывает форму и генераторы
│  ├─ options.js       настройки правил и значения по умолчанию
│  ├─ apache.js        генерация .htaccess
│  ├─ nginx.js         генерация конфига nginx
│  └─ curl.js          команды для проверки
└─ tests/              тесты генераторов (node:test)
```
